# SecureVault (Gestion-Password)

Un gestionnaire de mots de passe ultra-moderne, sécurisé et synchronisé dans le Cloud (via Supabase).

## Fonctionnalités
- Générateur de mots de passe puissant.
- Sauvegarde chiffrée et synchronisée avec Supabase (Row Level Security).
- Interface "Glassmorphism" magnifique, fluide et réactive.
- Authentification complète (Inscription, Connexion).
